# utils

A collection of self-hosted web utilities — personal tools, family-friendly apps, and AI-powered helpers.

**Live**: [utils.lzhdev.com](https://utils.lzhdev.com) *(coming soon)*

## Status

🚧 Under active development. The roadmap and architecture decisions are documented in [docs/PLANNING.md](docs/PLANNING.md).

## Tech stack

- [Next.js](https://nextjs.org) (App Router) + TypeScript
- Docker / docker compose, images published to GHCR
- GitHub Actions CI/CD — every push to `main` builds, tests, and deploys automatically

## Development

Setup instructions will land with the first scaffold (M1). See [AGENTS.md](AGENTS.md) for the current commands reference and [docs/PLANNING.md](docs/PLANNING.md) for the deployment architecture.
